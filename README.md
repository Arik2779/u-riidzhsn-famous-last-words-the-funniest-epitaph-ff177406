# Famous Last Words: The Funniest Epitaph

Entry for the [make.fun bounty](https://make.fun/bounty/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406): write the funniest possible famous last words as a single tombstone epitaph of at most 150 characters.

## The line

> My last words were going to be profound. Then I forgot them.

## Why it works

The line is first-person dying speech — the deceased speaking his own last words — so it is on subject as a tombstone epitaph. The joke is the whole line: he was about to deliver profound famous last words, and the punchline is that he forgot them. The famous last words are about failing to have famous last words. The twist lands on a single read with no explanation needed, it reads exactly like something carved on a stone, and it is short and quotable enough to repeat to a friend.

## How it runs

`main.py` (Python 3.13, standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). It is deterministic: the same 60 bytes on every run, no trailing newline.

```sh
python3 main.py
```
